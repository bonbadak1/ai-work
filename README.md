# 튼튼꽃 · 60+ 근력 놀이터

60대 이상을 위한 쉬운 근력 운동 안내 웹앱입니다. 운동 그림, 동작 설명, 완료 표시, 60초 휴식 타이머를 제공합니다.

## 사용 방법

1. `index.html`을 두 번 클릭해 인터넷 브라우저로 엽니다.
2. 운동 단계, 몸 상태, 운동 부위, 도구, 시간을 선택합니다.
3. 동작 설명을 읽고 운동한 뒤 **완료 표시**를 누릅니다.
4. 필요하면 **60초 쉬어가기**를 누릅니다.

완료 표시는 현재 화면에서만 유지되며 새로고침하면 초기화됩니다. 서버 저장 기능이나 로그인 기능은 없습니다. 통증이 있으면 운동을 중단하고 화면의 주의사항을 확인하세요.

## GitHub Pages에 올리기

저장소 맨 위에 `index.html`, `images` 폴더, `.nojekyll`, `README.md`, `.gitignore`를 올립니다. `images` 폴더 안에는 `exercise-guide.png`가 있어야 합니다.

GitHub 저장소의 **Settings → Pages → Deploy from a branch**에서 파일을 올린 브랜치와 **/(root)**를 선택하고 저장합니다. 별도의 빌드나 설치는 필요 없습니다.

파일 업로드 화면에서 직접 올릴 때는 원본 `strength-bloom` 폴더와 ZIP 파일을 올리지 마세요. `.gitignore`는 Git 프로그램으로 올릴 때만 자동으로 적용됩니다.

## 파일 구성

- `index.html`: 화면, 디자인, 동작 코드가 들어 있는 실행 파일
- `images/exercise-guide.png`: 운동 안내 그림
- `.nojekyll`: GitHub Pages에서 파일을 그대로 제공하도록 하는 빈 파일
- `.gitignore`: 원본 및 불필요한 파일을 Git 업로드에서 제외하는 목록

내부 파일 경로는 상대 경로입니다. NHS 참고 링크는 외부 웹사이트로 이동하는 링크입니다. 원본 ZIP과 압축 해제 폴더는 백업으로 보관하며 게시 대상에서 제외합니다. 게시용 파일에는 ChatGPT Sites 연결 코드나 전용 배포 설정이 없습니다.
